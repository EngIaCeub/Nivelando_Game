# Build First Exam Pack — TCE-GO TI 2026

Objetivo: usar TCE-GO como primeira implementação real sem contaminar o Core.

1. Leia `exam-packs/tce-go-ti-2026/README.md`.
2. Faça ingestão do edital oficial fornecido pelo usuário ou fonte oficial acessível.
3. Preencha manifest, facts/source-map, curriculum, resources e questions.
4. Marque assumptions explicitamente.
5. Gere plano inicial.
6. Rode schemas e acceptance.
7. Gere build standalone para GitHub Pages.
8. Não altere contratos do Core para acomodar peculiaridades do TCE-GO sem ADR R4.
