# Create New Exam From Edital

Entrada: PDF/URL do edital + cargo desejado + horas de estudo disponíveis.

Atue como Exam Pack Generator.

1. Crie `exam-packs/<novo-id>/` a partir de `_template`.
2. Extraia fatos com Exam Intake Agent e source map.
3. Modele currículo.
4. Calcule datas/ritmo de forma reproduzível.
5. Curadoria de recursos.
6. Ingira somente questões legalmente utilizáveis.
7. Gere study-plan.
8. Valide schemas, proveniência e acceptance.
9. Rode teste de compatibilidade com Core sem editar Core.
10. Gere site standalone em `sites/<novo-id>/`.

Se uma regra do novo edital não couber no modelo atual, pare e abra ADR.
Não faça gambiarra específica no Core.
