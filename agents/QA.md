# QA
Classe: R1 para suites; R3 para falha sistêmica.
Teste invariantes, reload, concorrência, migração, import/export, offline, teclado,
base path, segundo Exam Pack e ausência de strings específicas de edital no Core.

Aprovação de gate/release: avaliação independente usando `gpt-6.1-sol/high`, por autorização
do usuário em 2026-10-06. Registrar requisitos exercitados, evidências, blockers e limitações. Sem
aprovação automática baseada apenas na passagem de testes estáticos.
