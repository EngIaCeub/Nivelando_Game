# StudyOS / Nivelando Game — Guia rápido

## Instalar e começar

Abra a URL publicada e use a opção de instalar do navegador quando disponível. O aplicativo
funciona sob `/Nivelando_Game/` e guarda o progresso localmente neste dispositivo.

1. Defina sua meta diária em **Hoje**.
2. Faça o diagnóstico inicial para personalizar prioridades; ele não altera seu score simulado.
3. Siga a próxima atividade, responda questões e conclua para atualizar mastery e revisões.
4. Use **Revisões**, **Progresso** e os simulados empacotados para acompanhar a preparação.

## Backup e restore

Em **Configurações / Sobre**, use **Exportar meus dados** para baixar um JSON versionado.
Para restaurar, selecione o arquivo, confirme o resumo e confirme a importação; o estado atual
é salvo automaticamente antes do restore. Backups inválidos, incompletos, duplicados ou de
outro Exam Pack são recusados.

O backup inclui o domínio global (mastery) e as preferências, além do progresso deste
concurso. Restaurá-lo também substitui esse domínio compartilhado entre concursos.
Use **Baixar backup automático de recuperação** para guardar a cópia anterior ao restore.

## Atualizar a versão

Ao aparecer o aviso de atualização, pause ou conclua a atividade e feche as outras abas
StudyOS antes de confirmar. Se uma versão antiga não mostrar o aviso, abra
`https://engiaceub.github.io/Nivelando_Game/update.html` e siga a confirmação de pausa segura.

## Reset

Use **Resetar meus dados** somente se desejar apagar o progresso deste concurso e o domínio
global (mastery), inclusive o utilizado por outros concursos. Os históricos dos outros
concursos são preservados. A confirmação exige digitar `RESETAR`; uma cópia automática
de recuperação é salva antes da remoção.
