# New Exam Acceptance

Um novo Exam Pack é aceito se:
- schema válido;
- manifest possui fontes;
- fatos críticos são verified/derived, não assumption;
- curriculum possui IDs estáveis;
- resources têm status de verificação;
- questions têm proveniência;
- build standalone funciona;
- Core não precisou de alteração específica;
- progresso usa examId;
- export/import mantém o novo pack;
- analytics não mistura concursos;
- teste de smoke mobile passa.
