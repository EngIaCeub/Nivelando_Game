# Core Boundary Contract

O Core pode conhecer apenas interfaces genéricas:
ExamManifest, Curriculum, Resource, Question, StudyPlan, Event, Progress.

É proibido no Core:
- nomes de concursos;
- banca específica;
- datas específicas;
- matérias específicas;
- pesos específicos;
- URLs específicas de edital.

Teste arquitetural deve procurar vazamentos conhecidos.
