# If your repository already has AGENTS.md

Do not blindly overwrite it.

Merge these sections from the supplied root `AGENTS.md`:

- Product identity
- Non-negotiable functional contracts
- Design principle
- Architecture rules
- State integrity
- Visual QA
- Change discipline
- Model routing
- Agent delegation

Existing repository-specific build/test/security instructions should normally remain authoritative unless they conflict with an explicit newer project decision.
